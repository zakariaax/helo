Bulk TLD checker

Paste name ideas. For each one, see how many extensions are already registered, which are taken, and which look available.

Best free method: public RDAP. It is the registry’s own directory over HTTPS, with a clear found or not-found answer. DNS is the fallback when a TLD has no RDAP server, and also when that registry cannot be reached from the browser. Classic WHOIS is free but the wording is too inconsistent to trust for a bulk yes or no.

Use this

RDAP

IANA publishes which HTTPS server to ask for each TLD. HTTP 200 means the registry has the domain. HTTP 404 means it does not. That is the strongest free signal.

Owner contacts are often privacy-redacted. Redaction does not change the found / not-found answer. A not-found name can still be premium, reserved, or blocked at the moment you try to buy it.

Hint only

DNS

NXDOMAIN means the public DNS has no such name. That usually means unregistered, but a registered domain with no nameservers looks the same. Some TLDs answer for every name, so DNS says taken when it is not a normal registration.

This app uses DNS when IANA lists no RDAP server, and when the registry server does not answer the browser. Many registries block browser requests, which is why a full scan used to show a lot of unknowns. Those chips are labeled DNS. Availability from DNS is low confidence.

Skip for bulk

WHOIS

Port 43 WHOIS needs no key, but every registry writes a different paragraph. “Available”, “not found”, and “no match” are not safe to parse, and bulk queries get cut off.

Privacy redaction hides contact data you do not need for this job. This app does not query WHOIS.

Taken TLDs Available TLDs

Red is taken, green looks available, amber is unknown. Click a count to list those extensions. A failed lookup stays unknown and is never called available. RDAP availability is high confidence. DNS availability is a hint.

Nothing is uploaded to an account. A check asks IANA for the RDAP server list, then the registry for each RDAP TLD. If the registry cannot be reached, it asks Cloudflare or Google DNS-over-HTTPS and labels that as a DNS hint. Answers stay in this browser tab until you close it. Names are checked together, with a cap per registry so one slow server does not stall the rest.
